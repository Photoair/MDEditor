# 欢迎使用 轻量 Markdown 编辑器

这是一个用 **Rust** 编写的本地 Markdown 编辑器，**像 TXT 一样轻量**，即开即用。

## 特性

- 左侧编辑，网页预览
- 语法高亮
- 导出 HTML
- 纯本地，单文件运行
- 这些 发放大是

[豆包](https://www.doubao.com) 和 [百度](https://www.baidu.com)
