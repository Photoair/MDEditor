# mdedit — 轻量本地 Markdown 编辑器（Rust GUI 版）

一个像 TXT 编辑器一样轻量的 Markdown 编辑器，桌面 GUI，全宽编辑区（语法高亮），点按钮在默认浏览器中网页预览，绿色单文件，双击即用。

## 快速开始

直接双击 `mdedit.exe` 即可运行，无需安装、无需其他依赖。

也可以从命令行带一个文件路径打开：

```
mdedit.exe 文档.md
```

## 界面布局

- **顶部菜单栏**：文件 / 编辑 / 帮助
- **格式工具栏**：`▶ 网页预览` 按钮 + 标题、加粗、斜体、删除线、链接、行内代码、代码块、无序列表、有序列表、任务列表、引用、表格、分割线
- **全宽编辑区**：Markdown 编辑，带语法高亮（标题、代码块、引用、行内代码、加粗、斜体、链接等按不同颜色显示），自动加载系统中文字体（微软雅黑优先）
- **底部状态栏**：显示当前文件路径、字数、行数、光标所在行列

## 网页预览

点击工具栏 **`▶ 网页预览`** 按钮（或菜单「文件 → 预览（网页）」，或快捷键 `Ctrl+P`），程序会把当前内容渲染成完整 HTML 写入 `mdedit_preview.html`，并用**系统默认浏览器**打开。改完内容后再点一次即可刷新预览。

## 菜单功能

| 菜单 | 功能 |
|------|------|
| 文件 → 新建 / 打开 / 保存 / 另存为 | 基本文件操作 |
| 文件 → 导出 HTML... | 把 Markdown 渲染成独立 `.html` 文件另存 |
| 文件 → 预览（网页） | 用默认浏览器打开当前内容的网页预览 |
| 文件 → 设为 .md 默认打开方式 | 注册后双击 `.md` 文件直接用 mdedit 打开 |
| 编辑 → 复制 Markdown | 复制源码到剪贴板 |
| 编辑 → 复制 HTML | 复制渲染后的完整 HTML 到剪贴板 |
| 帮助 → 快捷键说明 | 查看所有快捷键 |

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+E` | 导出 HTML |
| `Ctrl+P` | 网页预览 |

## 自动保存

编辑内容会自动保存到程序同目录下的 `mdedit_draft.md`，下次启动自动恢复上次的草稿（带文件打开时除外）。

## 设为 .md 默认打开方式

菜单「文件 → 设为 .md 默认打开方式」，点击后注册当前程序为 `.md` / `.markdown` 文件的默认打开程序（写入当前用户注册表，无需管理员权限）。之后在资源管理器中双击 `.md` 文件就会用 mdedit 打开。

## 应用图标

程序内嵌了自设计的绿色圆角方块 + 白色 M 图标（`mdedit.ico`），在任务栏和文件资源管理器中显示。

## 绿色单文件说明

`mdedit.exe` 为静态编译的单个可执行文件（约 14 MB），只依赖 Windows 系统自带 DLL，不依赖任何第三方运行库，可直接拷贝到任意 Windows 10/11 电脑运行。程序为 **Windows GUI 子系统**，运行时不弹出任何控制台窗口。

## 从源码构建

环境：Rust stable（Windows GNU 工具链）+ MSYS2（ucrt64 的 gcc 作链接器）。

```powershell
$env:Path = "$env:USERPROFILE\.cargo\bin;C:\msys64\ucrt64\bin;" + $env:Path
cargo build --release
```

产物：`target\release\mdedit.exe`

## 技术栈

- `eframe` / `egui` 0.29：即时模式 GUI 框架
- `pulldown-cmark` 0.12：Markdown 解析
- `rfd` 0.14：原生系统文件对话框
- `winreg` 0.55：注册表（默认打开方式）
- `embed-resource`：嵌入应用图标

## 源码文件

| 文件 | 说明 |
|------|------|
| `src/main.rs` | 主程序：窗口、菜单、工具栏、全宽编辑区、文件读写、HTML 导出、网页预览、快捷键、默认打开方式 |
| `src/highlight.rs` | 编辑区 Markdown 语法高亮（LayoutJob） |
| `src/preview.rs` | Markdown 事件 → 富文本块，供导出 / 网页预览渲染 |
| `build.rs` / `app.rc` / `mdedit.ico` | 图标与版本信息嵌入 |
